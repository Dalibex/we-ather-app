# Grabaciones de los Scrum Meetings

```text
docs/dailys/
  sprint-1/
    2026-11-10.m4a
    2026-11-11.m4a
  sprint-2/
    ...
```

- Nombre: la fecha de la reunión, `AAAA-MM-DD`. Si hay dos el mismo día, añade `-2`.
- Formato: `.m4a` o `.mp3`, comprimido. GitHub rechaza archivos de más de 100 MB y avisa a partir
  de 50 MB.
- Se suben por pull request, como cualquier otro cambio (`docs(dailys): añadir daily del 10/11`).
